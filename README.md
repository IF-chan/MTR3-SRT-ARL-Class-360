# [MTR3] SRT Airport Rail Link Class 360
中文 | [English](#english)

## 中文
本资源包将[[MTR3/4] South East Asian Trains](https://modrinth.com/resourcepack/mtr34-south-east-asian-trains)中的曼谷机场铁路Class 360列车移植至MTR3（基于1.2版本）

（Class 360为MTR4独占，上述资源包的其他列车都可以在MTR3版本资源包找到）

资源包发布于[Modrinth](https://modrinth.com/resourcepack/mtr3-srt-airport-rail-link-class-360)

增加City Line涂装的无受电弓中间车和适配0高度轨道的列车，同步实现平步乘车（基于武汉轨道交通追加包的0高度轨道）
![City Line no-pantograph middle car](https://cdn.modrinth.com/data/cached_images/89d306308f272cf4427c3026bc5f4e183fbf7e22.jpeg)
![0 height rail version](https://cdn.modrinth.com/data/cached_images/5e021e84db8b041810ae74b28861aa19fb356758.jpeg)

本资源包包含16种不同编组，包括3/4节编组、City Line/Express涂装、5米/6米高度受电弓（从轨道节点所在高度计算）、常规高度/0高度轨道版列车。
可以通过修改mtr_custom_resources.json中的“model”来实现你想要的编组。

如果你想了解更多关于曼谷机场铁路Class 360列车的信息，可查看[该网页（日文注意）](https://2427junction.com/thailandbangkokarlcar.html)。

## English
This is a MTR3 port of SRT Airport Rail Link Class 360 in [[MTR3/4] South East Asian Trains](https://modrinth.com/resourcepack/mtr34-south-east-asian-trains) based on version 1.2.

Resource pack  is released on [Modrinth](https://modrinth.com/resourcepack/mtr3-srt-airport-rail-link-class-360).

Add City Line no-pantograph middle car and 0 Height rail version (based on 0 Height rail in Wuhan Metro Pack)
![City Line no-pantograph middle car](https://cdn.modrinth.com/data/cached_images/89d306308f272cf4427c3026bc5f4e183fbf7e22.jpeg)
![0 height rail version](https://cdn.modrinth.com/data/cached_images/5e021e84db8b041810ae74b28861aa19fb356758.jpeg)

This resource pack has 16 formations, including 3/4-car, City Line/Express livery, 5m/6m pantograph and normal height rail/0 Height rail version. 
You can change the formation by edit "model" in mtr_custom_resources.json.

If you want to know more about SRT ARL Class 360, you can see [this website (In Japanese)](https://2427junction.com/thailandbangkokarlcar.html).
